# مستندات توسعهٔ AbpToVolo

این مجموعه وضعیت پیاده‌سازی ابزار را توضیح می‌دهد؛ جایگزین گزارش تبدیل یک پروژهٔ واقعی نیست.

- [فرایند تبدیل و توسعهٔ ابزار](development-process.fa.md)
- [کارهای باقی‌مانده و تصمیمات باز](remaining-work-and-decisions.fa.md)
- [مهارت تحلیل ASP.NET Boilerplate](../skills/aspnetboilerplate/SKILL.md)
- [مهارت توسعه و اعتبارسنجی Volo ABP](../skills/volo-abp/SKILL.md)

مهارت‌ها داخل همین مخزن نگهداری می‌شوند. برای استفاده، فایل `SKILL.md` مربوط را به عامل توسعه معرفی کنید؛ این تغییر آن‌ها را در حساب ChatGPT نصب نمی‌کند. مستندات فرایند فارسی و دستورالعمل مهارت‌ها انگلیسی است تا شناسه‌ها و اصطلاحات کد دقیق باقی بمانند.

مرجع ترتیب واقعی مراحل، `MigrationEngine.DefaultSteps()` است. با اضافه یا حذف کردن مرحله، جدول فرایند را نیز به‌روز کنید. وضعیت کارها و تصمیمات باید همراه با شواهد آزمون تغییر کند.
